# ISA Manual — процессорное ядро kurBC

## 1. Общие характеристики

| Параметр | Значение |
|---|---|
| Разрядность слова данных / инструкции | 16 бит |
| Регистровый файл | 8 × 16 бит (R0…R7) |
| R0 | аппаратно равен 0, записи в R0 игнорируются |
| Тип архитектуры | одноцикловая (single-cycle), без конвейера |
| Инструкционная память (ROM) | 256 × 16, `$readmemb` |
| Оперативная память (RAM) | 64 × 16 |
| Сброс | синхронный, активный высокий; PC = 0, регистры = 0 |

## 2. Форматы инструкций

Поле `[15:12]` — opcode во всех форматах.

```
R-тип   : [15:12] op | [11:9] rd | [8:6] rs | [5:3] rt | [2:0] 000
LI      : [15:12] op | [11:9] rd | [8:0] imm9          (арифм. знаковое)
LOAD    : [15:12] op | [11:9] rd | [8:6] rb | [5:0] imm6
STORE   : [15:12] op | [11:9] rt | [8:6] rb | [5:0] imm6
BRANCH  : [15:12] op | [11:9] rs | [8:6] rt | [5:0] off6 (знаковое, PC-отн.)
JUMP    : [15:12] op | [11:8] 0000 | [7:0] addr8
HALT    : [15:12] op | [11:0] 0
```

## 3. Карта адресного пространства

| Блок | Адреса | Назначение |
|---|---|---|
| Instruction ROM | `0x00…0xFF` (8 бит адреса) | машинный код программы |
| Data RAM | `0x00…0x3F` (6 бит адреса) | данные; биты числа → `RAM[0…15]` |

## 4. Таблица системы команд

| OpCode | Мнемоника | Формат | Описание |
|---|---|---|---|
| `0000` | NOP | R | ничего не делает |
| `0001` | ADD rd, rs, rt | R | rd ← rs + rt |
| `0010` | SUB rd, rs, rt | R | rd ← rs − rt |
| `0011` | AND rd, rs, rt | R | rd ← rs & rt |
| `0100` | OR rd, rs, rt | R | rd ← rs \| rt |
| `0101` | XOR rd, rs, rt | R | rd ← rs ^ rt |
| `0110` | NOT rd, rs | R | rd ← ~rs |
| `0111` | SHL rd, rs, rt | R | rd ← rs << rt[3:0] (логический сдвиг влево) |
| `1000` | SHR rd, rs, rt | R | rd ← rs >> rt[3:0] (логический сдвиг вправо) |
| `1001` | LI rd, imm9 | LI | rd ← sign_ext(imm9) |
| `1010` | LOAD rd, imm6(rb) | LOAD | rd ← RAM[rb + sign_ext(imm6)] |
| `1011` | STORE rt, imm6(rb) | STORE | RAM[rb + sign_ext(imm6)] ← rt |
| `1100` | BEQ rs, rt, off6 | BRANCH | если rs == rt: PC ← PC+1+off6 |
| `1101` | BNE rs, rt, off6 | BRANCH | если rs != rt: PC ← PC+1+off6 |
| `1110` | JUMP addr8 | JUMP | PC ← addr8 |
| `1111` | HALT | — | PC замирает, сигнал `halted = 1` |

Примечания:
* знаковое поле (`imm9`, `imm6`, `off6`) расширяется арифметически до 16 бит;
* адрес ветвления относительный от **следующей** инструкции (PC+1);
* флагов АЛУ нет: ветвления сравнивают операнды напрямую;
* для LI/NOT/STORE поле `[2:0]`/`[5:0]` не используется (в программе — 0).

## 5. Структура процессора (одноцикловый)

```
PC → ROM → Control Unit ─┬→ Register File (3 порта чтения) → ALU → mux → запись в RF
                         │                              ↘ addr → RAM (combinational read,
                         │                                      синхронная запись)
                         └→ блок ветвлений (сравнение RS/RT) → выбор следующего PC
```

Каждая инструкция выполняется за один такт: чтение ROM и RAM — комбинаторные,
запись в RAM и обновление PC/регистров — по фронту clk.

## 6. Формат выходных данных (задача варианта)

Вход: 16-битная константа `N = 16'hACE1`, собирается в программе из двух
констант LI (`(high9 << 7) | low7`).

Выход: массив из 16 слов в `RAM[0…15]`,
`RAM[i] = (N >> i) & 1` — побитовая раскладка числа (0 или 1 в каждом слове).
